# falcon-entwurf

Konzept-Entwürfe von Falcon Eye für Kunden – veröffentlicht unter **https://entwurf.falcon-eye.de/<kunde>/** (GitHub Pages, noindex).

Alte Adressen `https://falcon-eye.de/entwurf/<kunde>/…` leiten automatisch hierher weiter (inkl. Unterseiten, Parametern und #-Ankern, z. B. Planer-Links aus Mails).

Quellen der Seiten liegen in den jeweiligen Build-Ordnern (pel, erb, hud, kl2, gt2, ver, zh2, kow); hier liegt nur das fertige Ergebnis.
